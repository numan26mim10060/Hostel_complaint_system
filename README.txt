HOSTEL COMPLAINT SYSTEM - MODULAR VERSION

main.py
Main program. Displays the menu and calls functions from the modules.

complaint_module.py
Handles registering complaints.

view_module.py
Handles viewing and searching complaints.

manage_module.py
Handles updating and deleting complaints.

HOW TO RUN:
Keep all four .py files in the same folder and run main.py in VS Code.
