# Problem Statement

## Hostel Complaint System

Hostel students may face problems related to rooms, facilities, maintenance, and other hostel services. Managing these complaints manually can make it difficult to register, search, update, and track complaints.

The **Hostel Complaint System** is a Python-based console application developed to provide a simple way to manage hostel complaints.

The system allows the user to:
- Register a new complaint
- View all registered complaints
- Search for a complaint using a room number
- Update the complaint status
- Delete a complaint
- Exit the system

Each complaint contains the student's name, room number, category, problem description, and status. The initial status of a newly registered complaint is `pending`.

The current version stores complaints in a Python list while the program is running. Permanent storage is not included in the current version.
